## Qu'est-ce que c'est

VocabRadar est une extension de navigateur (Chrome / Edge / Firefox) pour
apprendre du vocabulaire. Elle signale les mots que vous ne connaissez
probablement pas —selon la fréquence d'usage— et montre leur sens immédiatement.
**42 langues**. Sans inscription, sans compte ; tout est consulté en local.

Fonctions : mots nouveaux dans les vidéos (Bilibili / YouTube) et sur toute page
web, sous-titres annotés, reconnaissance vocale locale (Whisper), OCR et
discussion avec l'IA.
