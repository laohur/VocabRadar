## ما هو

VocabRadar إضافة متصفح (Chrome / Edge / Firefox) لتعلّم المفردات. تُبرز الكلمات التي
قد لا تعرفها —حسب تكرار الاستخدام— وتعرض معناها فورًا. **42 لغة**.
بدون تسجيل، بدون حساب؛ كل الاستعلامات تتم محليًا.

الوظائف: كلمات جديدة في الفيديو (Bilibili / YouTube) وأي صفحة ويب، ترجمات مع
حاشية، تعرّف صوتي محلي (Whisper)، OCR ودردشة مع الذكاء الاصطناعي.
