## これは何

VocabRadar は語彙学習のためのブラウザー拡張機能（Chrome / Edge / Firefox）です。
使用頻度に基づいて、あなたが知らないかもしれない単語をハイライトし、その場で
意味を表示します。**42 言語**に対応。登録不要・アカウント不要、すべてローカルで検索します。

機能：動画（Bilibili / YouTube）やあらゆるウェブページの未知語、注釈付き字幕、
ローカル音声認識（Whisper）、OCR、AI チャット。
