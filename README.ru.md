## Что это

VocabRadar — расширение для браузера (Chrome / Edge / Firefox) для изучения
словарного запаса. Оно выделяет слова, которые вы, вероятно, не знаете —по
частоте употребления— и сразу показывает их значение. **42 языка**.
Без регистрации, без аккаунта; всё ищется локально.

Возможности: новые слова в видео (Bilibili / YouTube) и на любой веб-странице,
субтитры с примечаниями, локальное распознавание речи (Whisper), OCR и чат с ИИ.

| **Edge** | [Дополнения Microsoft Edge — VocabRadar](https://microsoftedge.microsoft.com/addons/detail/hcpmjphbnjhlfahimifbkhfjafkfjbbb) |
