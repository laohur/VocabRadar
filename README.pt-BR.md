## O que é

O VocabRadar é uma extensão de navegador (Chrome / Edge / Firefox) para aprender
vocabulário. Ele marca as palavras que você provavelmente não conhece —segundo a
frequência de uso— e mostra o significado na hora. **42 idiomas**.
Sem cadastro, sem conta; tudo é consultado localmente.

Funções: palavras novas em vídeos (Bilibili / YouTube) e em qualquer página web,
legendas com anotações, reconhecimento de voz local (Whisper), OCR e chat com IA.
