## Was es ist

VocabRadar ist eine Browsererweiterung (Chrome / Edge / Firefox) zum Lernen von
Wortschatz. Sie markiert Wörter, die du wahrscheinlich nicht kennst —anhand der
Häufigkeit— und zeigt sofort ihre Bedeutung. **42 Sprachen**. Keine Registrierung,
kein Konto; alles wird lokal nachgeschlagen.

Funktionen: neue Wörter in Videos (Bilibili / YouTube) und auf jeder Webseite,
Untertitel mit Notizen, lokale Spracherkennung (Whisper), OCR und KI-Chat.
